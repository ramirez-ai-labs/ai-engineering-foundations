# Resources

This folder holds supporting material for the main curriculum.

Use it for:

- reading lists
- study checklists
- curriculum positioning notes
- diagrams
- quick-reference notes

The purpose of `resources/` is to support the numbered learning path, not to replace it. A learner should still be able to move through the main folders in order and use this folder for reinforcement.

## Good Resource Types

- short glossaries for AI and systems terms
- curated book recommendations
- interview review checklists
- architecture diagrams tied to a lesson
- references to deeper labs or external repos
