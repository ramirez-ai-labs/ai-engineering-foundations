# Repo Positioning Map

## Canonical Repo

- `ai-engineer-cs-refresh` is the source of truth for CS refresher curriculum and learning artifacts.
- Dev/Mission receives a copied/adapted version from this repo.

## How This Repo Differs From Existing Repos

- `edge-ai-agent-lab`: Production-style edge/agent implementation lab.
- `latam-genai-lakehouse-benchmark`: Regional LLM benchmark and data platform evaluation.
- `latam-rag-quality-gate`: RAG quality control and gating workflows.
- `ai-architecture-showcase`: Architecture patterns showcase across systems styles.
- `codex-systems-lab`: Inference and agent-system experimentation.
- `openai-codex-ds-showcase`: Analytics/evaluation pipeline for coding workflows.
- `rag-evaluation-lab`: Focused RAG evaluation lab.
- `OpenAI-Tutorials`: API-first tutorials and demos.

This refresher repo should stay focused on fundamentals progression:

1. data structures
2. algorithms
3. systems
4. AI foundations
5. integrated mini-projects

## Boundary Rules

- Put foundational concept notes and exercises here.
- Put production-grade specialized labs in their dedicated repos above.
- If a mini-project grows beyond refresher scope, graduate it to its own repo and link back here.

## Cross-Link Scope

Root README currently includes a "Related Deep-Dive Repos" section. Keep these reference paths aligned:

- `rag-evaluation-lab` from `04-ai-foundations` and `05-mini-projects`
- `ai-architecture-showcase` from `03-systems`
- `edge-ai-agent-lab` from `05-mini-projects`
- `OpenAI-Tutorials` from `04-ai-foundations/resources`

## Dev/Mission Copy Rules

- Copy only stable content from this repo (reviewed notes, solved exercises, polished mini-project specs).
- Keep teaching-only content downstream: cohort prompts, instructor notes, pacing adjustments.
- Upstream improvements in core material before the next copy cycle.

## Suggested Cadence

- Weekly: push canonical updates here.
- Bi-weekly: copy a curated snapshot to Dev/Mission.
- Monthly: boundary review to prevent repo overlap.
