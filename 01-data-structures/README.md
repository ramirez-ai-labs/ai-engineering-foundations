# 01 – Data Structures

Refresh core structures you actually use in AI work: arrays, hash maps, linked lists, trees, and graphs.

## Files

| File | Concepts |
|------|----------|
| `ArrayExamples.java` | Arrays, indexing, iteration, basic ops |
| `HashMapExamples.java` | Hash maps, O(1) lookup, key-value semantics |
| `LinkedListDemo.java` | Singly/doubly linked list, pointers, traversal |
| `TreeBasics.java` | Binary tree, BST, traversal (in-order, etc.) |
| `GraphDFSAndBFS.java` | Graph representation, DFS, BFS |

## How to run

From this directory (or repo root):

```bash
javac *.java && java ArrayExamples
# or: java HashMapExamples, java LinkedListDemo, etc.
```

Work through the files in order; each has a `main` that demonstrates the structure.
