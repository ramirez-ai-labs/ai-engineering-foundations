# 02 – Algorithms

Light algorithm refresh: recursion, sorting, searching, and Big-O. Not competitive programming — just the ideas you need for interviews and system design.

## Files

| File | Concepts |
|------|----------|
| `BinarySearch.java` | Binary search on sorted array, O(log n) |
| `MergeSort.java` | Divide-and-conquer, recursion, O(n log n) |
| `TwoSum.java` | Hash map for O(n) two-sum; brute force O(n²) |
| `TimeComplexityNotes.java` | Big-O refresher with small examples |

## How to run

```bash
javac *.java && java BinarySearch
# or: java MergeSort, java TwoSum, java TimeComplexityNotes
```
